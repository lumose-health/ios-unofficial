# Tandem replay traces

This repository is public. Every committed trace must use synthesized or offset values, doses, and serial numbers so no person's data or device identity can be recovered. A de-identified capture needs a named reviewer before it lands.

Format v1 is a JSON object with `format`, `version`, `vendor`, `description`, `pumpTimeZone`, `provenance`, and nonempty `frames`. Provenance records `source`, `method`, and `reviewedBy`. Each frame gives `channel`, ISO-8601 `receivedAt`, lowercase hex `notifications`, and a `note`. Unknown keys are refused at every level. Receive times must never go backwards. A trace is limited to 4 MiB and 4096 frames (`TraceFile.maximumFileBytes`, `TraceFile.maximumFrameCount`). The reader reassembles and decodes notifications through TandemWire. At activation, one fixed offset, `now - max(receivedAt)`, maps the newest frame's phone receive time to replay start. Every replayed glucose, IOB and out-of-range timestamp is that frame's `receivedAt` plus the offset, so intervals are preserved, nothing is later than replay start, and a skewed pump clock or wrong `pumpTimeZone` cannot shift glucose relative to IOB. The pump's EGV timestamp is still decoded and a bad one halts replay, but it does not set the replayed time.
